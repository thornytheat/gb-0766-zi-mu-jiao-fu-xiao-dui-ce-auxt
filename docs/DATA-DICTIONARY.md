# 字幕与切版定义

- 字幕 CSV 六列 `cue_id,track,format,in,out,text`。旧表头 `legacy_id,time_in,time_out` 对应 `cue_id,in,out`。UTF-8 可带 BOM。跨行引用从原件起始物理行定位。空串与 `-`、`N/A`、`NULL`、`未知` 都按缺字段处理。编号为字符串。同轨同号完整内容一致只采一条，冲突全组隔离。
- 源时钟固定为 30000/1001 帧每秒，目标为 24 帧每秒。`FRAME` 使用整数源帧。`DF` 用分号，非十整倍数分钟的首秒跳过标签 `;00`、`;01`，合法帧仍连续。`NDF` 用冒号并按名义 30 编号。`SRT`、`VTT` 代表以逗号或小数点分隔毫秒的时码列。墙钟以有理数换算源帧。
- 切版 `cut,start,end,target,kind` 用左闭右开源帧区间，类型为 `KEEP` 或 `REMOVE`。`KEEP` 必须给整数目标起帧，`REMOVE` 的 `target` 留空。源区间或目标区间重叠使整份切版失败。切版未覆盖区间是 `GAP`，即待证。
- 连续目标坐标为 `target + (源坐标 - start) × 1001/1250`。交付帧序号为落在区间内的整数网格点，因此两个端点都向上取整。显示出的目标重叠按轨道对交付整数帧做扫描线，重叠深度大于等于两条的每一帧只计一次。
- 源覆盖在同一轨内取并集，再对不同轨道累加。所有源帧量用十进制整数字符串或 `分子/分母`。原覆盖 = 已交付源覆盖 + 剪辑移除 + 待证 + 许可撤回。时码无效或身份矛盾无法估时，行数单计。证据 JSON 含原件、行证、散列、规则版本及归档 UTC。
- 撤回清单按 `cue_id,track,start,end`（`track` 可省）声明某句字幕失去许可的左闭右开源帧。`POST /api/runs` 或前五张校对页的 `POST /api/check/<sheet>` 可用 `withdrawals` 字段提交 JSON 数组或 CSV 文本，区间会先合并再按字幕归并，因此等价提交只登记一次。撤回只裁掉命中的源帧，同一句仍照旧覆盖其余部分。
- 命中仍在 `KEEP` 内的撤回片段单列 `WITHDRAWN`，不参与撞帧扫描，也不进交付；落在 `REMOVE` 或 `GAP` 的撤回不改变交付画面。覆盖对账里，若禁播源帧仍被另一句获准字幕覆盖，该帧仍计入交付覆盖，只有在没有其他获准字幕覆盖时才计入 `许可撤回`，因此 原覆盖 = 交付 + 剪辑移除 + 待证 + 许可撤回 始终守恒。
- 撤回先写入按字幕原件指纹隔离的 `withdrawals/` 台账，再签发新包；台账可追加，重复提交同一撤回按内容去重。归档下载与 `GET /api/delivery/<id>` 会按台账复查：只要该包的任一 `KEEP` 片段仍含禁播源帧即返回 409 `WITHDRAWN`，撤回只落在已剪掉画面或待证段时原包照常下载。`POST /api/runs/<id>/repeat` 复算原包内容，不重新套用后续撤回。
