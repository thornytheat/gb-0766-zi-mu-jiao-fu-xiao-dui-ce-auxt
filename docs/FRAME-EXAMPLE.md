# C101 帧边界复算

C101 原行 2，覆盖从 900 到 1300 源帧。A-01 保留 100 源帧，A-02 移除 200 源帧，B-01 保留 100 源帧。B-01 从源 1200 锚到目标 810，末端是 `810+100×1001/1250=890.08`，因此交付 `[810,891)`。

三字幕在 `[855,883)` 同时覆盖，计 28 个目标帧。源帧用并集对账，三条叠加不会增加 28 帧的源覆盖。

## C113 撤回复算

撤回 C113 的全部 35 个源帧（`1255..1290`）。这 35 帧仍在 C101 与 C102 的获准画面里，交付维持 740、许可撤回为 0；`[855,883)` 从三句相撞降为两句相撞，每帧只计一次，所以目标重叠仍是 65。若撤回只与 C101 撞帧的 C117（`930..940`，8 个目标帧），那处撞帧整体消失，目标重叠降为 57，交付仍是 740。若撤回 C104 的 10 个无他句覆盖的交付源帧（`1800..1810`），交付降为 730、许可撤回 10，总账 1140 仍守恒。
